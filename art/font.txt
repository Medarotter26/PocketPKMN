; WalkerBox font - an original proportional pixel font for the Pokewalker LCD.
; Designed for this project (not copied from any existing font or game).
;
; Format: a header line "[c]" names the character (one character, or one of
; the names space / e_acute / E_acute / ... - the names after "~" are listed
; in tools/pwimg.py EXTRA with their code points), followed by the glyph rows
; and a blank line. '#' = ink, '.' = paper. All rows of a glyph have the same
; width. A glyph has 12 rows: 9 rows of cap height (baseline under row 9) and
; 3 descender rows. A glyph may have 14 rows: then the first 2 rows are the
; accent zone above the capitals (accented capitals need it).
; v0.81 (names step 1, owner: "Go 12"): accented letters of French,
; German, Spanish and Italian names (lower case: accents on rows 2-3 of the
; 14; capitals: rows 0-1; the accented A has no apex pixel so the accent does
; not run into it; i with an accent is a dotless 3-px i), oe / OE, sharp s,
; male / female signs.
; Metrics: cap height 9, x-height 6, descender 3, line height 16,
; letter gap 1 px (advance = width + 1), space = 3 px.
; tools/gen_art.py turns this file into source/pw_font.c.
